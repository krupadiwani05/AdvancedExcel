# 📺 Sony R.I.S.E (Research, Innovate, Solve, Excel)

## 📌 Project Overview

Sony R.I.S.E (Research, Innovate, Solve, Excel) is an Advanced Excel project focused on analyzing media content data using Excel-based data analytics techniques.

The project demonstrates how Excel can be used to clean, transform, analyze, and visualize large datasets to generate meaningful business insights.

---

## 🎯 Project Objectives

The project was designed to:

- Clean and prepare raw content data for analysis
- Extract meaningful information from date fields
- Apply logical conditions for data classification
- Perform data retrieval using lookup functions
- Analyze content trends across languages and genres
- Generate summary reports using Pivot Tables
- Design an interactive dashboard for business insights
